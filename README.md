# JindAI Downloads

This repository is for downloading JindAI CLI and JindAI Application releases. Source code is not included at this time. All rights reserved.

## Releases

Find all available downloads on the [Releases](https://github.com/kul1/jindai_download/releases) page.

### Available Packages

| Package | Description |
|---------|-------------|
| `jindai-macos-arm64.tar.gz` | JindAI Application — macOS Apple Silicon (M1/M2/M3) |
| `jindai-macos-x86_64.tar.gz` | JindAI Application — macOS Intel |
| `jindai-cli-macos-arm64.tar.gz` | JindAI CLI — macOS Apple Silicon (M1/M2/M3) |
| `jindai-cli-macos-x86_64.tar.gz` | JindAI CLI — macOS Intel |

## Installation

Download the appropriate package for your system from the Releases page and follow the instructions in the release notes.
