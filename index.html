🔄The Folder → Session → PR Workflow

JindAI is designed around a simple mental model: one project folder, one session per task, one session per pull request. Here's how it fits together:

1
📁

Set your Project Folder

Click 📁 Folder in the toolbar and pick your git repository root. JindAI reads your current branch, detects your DNA mindmap, and auto-seeds AGENTS.md with project context. From this moment, every session name is derived from your branch.

→
2
💾

Create a Session per Issue

Open Sessions and click New. The name is pre-filled with your current branch (e.g. fix-auth-bug). Save your conversation at any point — adapter settings, preview context, and conversation snapshot are all stored. Load it tomorrow and resume instantly.

→
3
🔀

Sessions follow your PRs

When you push a PR, rename the session to match. Sessions live in .jindai/sessions/ inside your repo and are committed alongside the code. Your team can see which AI conversations belong to which feature — without sharing API keys.

💡 Tip: When you first open JindAI with no project set, the Preview panel shows a Getting Started guide. Once you pick a folder, JindAI shows your project's AGENTS.md in Preview — giving every AI conversation immediate access to your project's purpose, architecture, and conventions.

📦Installation

1

Download the DMG

Click the download button above to get JindAI-<version>.dmg for your Mac.

2

Open the installer

Double-click the DMG, then drag JindAI into your Applications folder.

3

First launch — bypass Gatekeeper

Right-click JindAI.app → Open → Open. macOS remembers this after the first approval.

4

Pick an adapter & API key

Click the adapter pill in the top bar → Select Adapter → choose your AI provider and enter your API key.

5

Set your Project Folder

Click 📁 Folder in the toolbar and pick your git repository. JindAI reads your branch and scaffolds dna/index.mm and AGENTS.md automatically.

6

Create your first Session

Open Sessions → New. The name defaults to your branch name. Save a session at the start of each feature or PR so you can always restore your AI context later.

⌨️CLI — jindai-cli

A separate binary for shell scripting, CI pipelines, and terminal-first workflows.

# Show all commands
$ jindai-cli --help

# Send a prompt
$ jindai-cli /a "Explain this function"

# Switch AI adapter
$ jindai-cli /adapter opencode

# Switch model
$ jindai-cli /model claude-sonnet-4-5

# Run a quick test
$ jindai-cli /test

Download the CLI binary separately:

# Install to PATH

$ sudo mv ~/Downloads/jindai-cli-macos-arm64 /usr/local/bin/jindai-cli

🛟FAQ

macOS says "JindAI cannot be opened because the developer cannot be verified"

This is a standard Gatekeeper warning for apps not yet in the Mac App Store. Right-click (or Control-click) JindAI.app → Open → click Open. After the first approval macOS remembers your choice.

The app opens but shows "No adapter loaded"

Click the adapter pill at the top → Select Adapter → choose your provider (OpenCode, Anthropic, etc.) and enter your API key. The setting is saved per terminal/session automatically.

What is a Project Folder and why do I need it?

The Project Folder is the root of your git repository. Setting it unlocks: branch-aware session naming, DNA mindmap auto-detection, and AGENTS.md auto-seeding. Without a project folder JindAI still works, but session names are generic and git context is unavailable. Click 📁 Folder in the toolbar to set it.

What are Sessions and when should I create one?

A Session is a full snapshot of your AI conversation context — adapter, model, preview/pretext, and conversation history. Create a new session at the start of each feature branch or pull request so you can always restore exactly where you left off. Sessions are stored in .jindai/sessions/ inside your project repo and travel with your code.

How do Sessions relate to Git branches and PRs?

When you create a new session, the name defaults to your current git branch (e.g. fix-auth-bug). Rename sessions to match your PR title. Since sessions live inside the repo, your team sees which AI conversations belong to which feature — without sharing credentials.

How do I update JindAI?

JindAI checks for updates in the background on startup. When a new release is ready, a green indicator appears in the About panel. You can also download the latest DMG from the Releases page and drag the new app into Applications. Your sessions, settings, and project data are preserved.

Where are my settings and sessions stored?

App settings: ~/Library/Application Support/JindAI/
Sessions (snapshot manager): <project>/.jindai/sessions/ or the fallback above.
Auto-save sessions (V2): ~/Library/Application Support/JindAI/sessions/
You can back up or copy these folders between machines.

Can I use JindAI without an internet connection?

JindAI requires a network connection to reach your AI provider's API. The app itself is fully local — no data is sent anywhere except your configured adapter endpoint.

How do I report a bug or request a feature?

Open an issue on the Issues page. Please include your macOS version, JindAI version (shown in the About dialog), and steps to reproduce.
