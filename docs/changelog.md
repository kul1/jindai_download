## v1.1.0 — 2026-03-03

**Initial public release**

- GUI window mode with full conversation view
- Compact (input-only) view toggle
- OpenCode and Anthropic adapter support
- Per-terminal session isolation
- `jindai-cli` command-line interface with `/a`, `/adapter`, `/model`, `/test` commands
- Adapter connection test with detailed diagnostics
- Restart and Exit from within the app
